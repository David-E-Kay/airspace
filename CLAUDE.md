# Multi Agent Dashboard

## Executing implementation plans

**When a written implementation plan in `docs/superpowers/plans/` is ready to execute,
invoke `superpowers:subagent-driven-development` and dispatch one implementer subagent
per task.** This is an instruction, not an option to offer: do not execute the plan
turn-by-turn in this session instead. Mechanics — who implements, who reviews each task,
and verifying the plan against the tree immediately before every dispatch — are in the
global `CLAUDE.md` §4.
